# Party Chat
I made a project, where you can send messages anonymously :D

## Why is it useful:
- You can talk with random people from around the world
- There is no requirement to register or anything 
- you can customize your messages as you want :D
- It's actually very light-weight

How to download it:
 - Click on code button and download it as zip
 - open up the zip and after you can start edit the code :)
